¿Qué es OCS Inventory?

OCS Inventory NG (Open Computers and Software Inventory Next Generation) es una herramienta de código abierto diseñada para el inventario automático de hardware y software en redes informáticas. Permite a los administradores conocer en todo momento el estado de los equipos de la red: procesador, memoria RAM, disco duro, sistema operativo, aplicaciones instaladas, etc.

La arquitectura de OCS se divide en dos componentes principales:

  • Servidor OCS (ocsreports + ocsinventory-server): aplicación web PHP que recibe, almacena y muestra los inventarios. Se apoya en un servidor web Apache y en una base de datos MySQL/MariaDB.
  • Agente OCS: programa instalado en cada equipo cliente (Windows, Linux, macOS) que recoge la información de hardware y software y la envía al servidor de forma periódica o bajo demanda.

Instalación en el servidor Ubuntu

Paso 1 – Arranque del servidor (equipo Dell)

El servidor donde se instaló OCS es un equipo Dell. Al encenderlo muestra la pantalla de inicio con el logo corporativo de Dell mientras el hardware realiza el POST y el sistema operativo Ubuntu comienza a cargar. No se requiere ninguna acción en este punto; simplemente se espera a que Ubuntu arranque completamente y se accede a la sesión de terminal.

Paso 2 – Instalación de dependencias: Apache, PHP y MySQL

OCS Inventory requiere un servidor web (Apache2), el intérprete PHP y sus extensiones, y un motor de base de datos (MySQL). Instalamos todos estos paquetes desde los repositorios oficiales de Ubuntu con apt. PHP necesita extensiones específicas como php-mysql, php-xml, php-gd y php-mbstring, entre otras.

Paso 3 – Instalación del paquete OCS Inventory

Con las dependencias instaladas, procedemos a instalar los dos paquetes principales de OCS: ocsinventory-server (el servidor que recibe los agentes) y ocsinventory-reports (la interfaz web de administración).

Paso 4 – Configuración del firewall (UFW)

Para que los agentes puedan comunicarse con el servidor, debemos permitir el tráfico en el puerto 80 (HTTP) a través del firewall UFW.

Configuración de la base de datos MySQL

OCS Inventory almacena todo el inventario en una base de datos MySQL. Es necesario crear una base de datos específica y un usuario con privilegios sobre ella antes de ejecutar el instalador web de OCS.

Paso 5 – Acceso a MySQL y creación de la base de datos

Accedemos a la consola de MySQL como administrador con el comando: 

mysql -u root -p

Una vez dentro, creamos la base de datos y el usuario que OCS utilizará para conectarse. Es importante asignar todos los permisos necesarios (GRANT ALL PRIVILEGES) y aplicar los cambios con FLUSH PRIVILEGES.

Paso 6 – Verificación de la base de datos

Comprobamos que la base de datos y el usuario se han creado correctamente.

Habilitación de módulos y configuración de Apache

Paso 7 – Activación de las configuraciones de OCS en Apache

Ejecutamos los siguientes dos comandos para habilitar ambos componentes: 

a2enconf ocsinventory-reports.conf
a2enconf z-ocsinventory-server.conf

Tras ejecutarlos, recargamos Apache: 

systemctl reload apache2

Paso 8 – Primer acceso al asistente web de instalación de OCS

Desde un navegador en la misma red accedemos a http://192.168.1.18/ocsreports/ (la IP real del servidor en el aula). La página cargó el formulario de instalación web de OCS-NG Inventory Installation con los siguientes campos a rellenar:

  • MySQL login: usuario de MySQL creado para OCS
  • MySQL password: contraseña de ese usuario
  • Name of Database: nombre de la base de datos (por defecto ocsweb)
  • MySQL HostName: dirección del servidor MySQL (localhost si está en la misma máquina)
  • MySQL Port: 3306 (puerto por defecto de MySQL)
  • Enable SSL / SSL mode / SSL key path / SSL certificate path / CA certificate path: opcionales, se dejan en blanco si no se usa HTTPS

El formulario también mostraba dos avisos en rojo importantes:

  • "WARNING: You will not be able to build any deployment package with size greater than 2MB. You must raise both post_max_size and upload_max_filesize in your vhost configuration to increase this limit." — indica que para subir paquetes de despliegue mayores de 2MB hay que ajustar parámetros en php.ini o en la configuración del virtualhost de Apache.
  • "WARNING: If you change default database name (ocsweb) or user (ocs), don't forget to update the file z-ocsinventory-server.conf in your Apache configuration directory." — avisa de que si se usa un nombre de BD o usuario diferente al estándar, hay que editar también el fichero de configuración de Apache del servidor OCS.

Una vez rellenados los datos, pulsamos Send para que OCS cree las tablas automáticamente en la base de datos.

Paso 9 – Panel de administración de OCS

Una vez completada la instalación, accedemos al panel con las credenciales por defecto (admin / admin, que deben cambiarse inmediatamente).

Paso 10 – Configuración adicional del servidor

Ajustamos parámetros como la frecuencia de inventario, gestión de duplicados y permisos de acceso a la interfaz web.

Paso 11 – Verificación del servidor

Comprobamos que todos los servicios (Apache y MySQL) están activos y que la interfaz web responde correctamente.

Instalación del agente OCS en Windows 11 Pro

Con el servidor en funcionamiento, instalamos el agente OCS en el equipo Windows 11 Pro. El agente utilizado es la versión 2.11.0.1, el mismo instalador que se documentó en la Actividad 1 como tercera aplicación.

Paso 12 – Descarga e inicio del instalador del agente

Descargamos el instalador del agente OCS para Windows (OCS-Windows-Agent-2.11.0.1.exe) y lo ejecutamos con permisos de administrador.

Paso 13 – Configuración del agente: URL del servidor

Durante la instalación indicamos la URL del servidor OCS. La IP del servidor en el aula es 192.168.1.18, por lo que la URL queda: 

http://192.168.1.18/ocsinventory

Es importante apuntar al endpoint /ocsinventory (el servidor de comunicación con agentes), y no a /ocsreports (la interfaz web).

Paso 14 – Opciones de instalación y finalización

Seleccionamos la opción de ejecutar como servicio de Windows para que el inventario se envíe automáticamente en cada arranque y de forma periódica. Finalizamos el asistente.

Paso 15 – Primer inventario y verificación en el servidor

Una vez instalado el agente, podemos forzar el envío del primer inventario ejecutando el agente manualmente desde línea de comandos (como administrador): 

"C:\Program Files (x86)\OCS Inventory Agent\OCSInventory.exe" /server:192.168.1.18 /now

Transcurridos unos segundos, el equipo aparecerá en el panel de administración web de OCS con todos sus datos de hardware y software inventariados.
