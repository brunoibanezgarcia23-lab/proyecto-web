Actualización del sistema

Antes de instalar cualquier servicio, actualizamos los repositorios de nuestro servidor para asegurarnos de tener los paquetes más recientes.

Actualizar repositorios

sudo apt update && sudo apt upgrade -y

sudo systemctl status apache2

Instalación y Configuración del Servicio FTP

Instalamos vsftpd (Very Secure FTP Daemon) para gestionar la transferencia de archivos de forma segura.

Instalamos el servicio

sudo apt install vsftpd -y

Configuramos el archivo principal

Abrimos el archivo de configuración:

sudo nano /etc/vsftpd.conf

Modificamos o añadimos las siguientes líneas para permitir la escritura y aislar a los usuarios:

  • anonymous_enable=NO — Desactiva el acceso anónimo
  • local_enable=YES — Permite el acceso a usuarios locales de Ubuntu
  • write_enable=YES — Permite subir y modificar archivos
  • chroot_local_user=YES — Bloquea a los usuarios en su carpeta de inicio por seguridad

Corregimos permisos y reiniciamos

Por seguridad, vsftpd no permite iniciar sesión si la carpeta raíz del usuario tiene permisos de escritura compartidos. Ejecutamos los siguientes comandos:

sudo mkdir -p /home/usuario/ftp/files sudo chown -R nobody:nogroup /home/usuario/ftp sudo chmod a-w /home/usuario/ftp sudo chown -R usuario:usuario /home/usuario/ftp/files

Añadimos al final de /etc/vsftpd.conf:

user_sub_token=$USER local_root=/home/$USER/ftp

Reiniciamos el servicio

sudo systemctl restart vsftpd

Configuramos el Cortafuegos (UFW)

Abrimos los puertos necesarios para que tanto el servidor web como el FTP sean accesibles desde la red.

Permitimos la Web

sudo ufw allow 'Apache Full'

Permitimos el FTP

sudo ufw allow 20/tcp sudo ufw allow 21/tcp

Aplicamos los cambios

sudo ufw reload
